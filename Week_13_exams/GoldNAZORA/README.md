# 💛 GoldNAZORA – Online Takı Mağazası

GoldNAZORA, altın ve gümüş takı koleksiyonlarını sergilemek amacıyla geliştirilmiş bir e-ticaret web projesidir.

Proje kapsamında kullanıcıların ürünleri inceleyebileceği, koleksiyonlar arasında gezinebileceği, sepet işlemlerini gerçekleştirebileceği ve teslimat bilgilerini girerek sipariş oluşturabileceği bir alışveriş deneyimi hedeflenmiştir.

## ✨ Özellikler

- Ana sayfa ve marka tanıtım alanı
- Ürün koleksiyonlarını görüntüleme
- Kategorilere göre ürün filtreleme
- Ürün detay sayfaları
- Kullanıcı giriş sayfası
- Sepete ürün ekleme ve sepet işlemleri
- Teslimat bilgileri formu
- Sipariş onaylama işlemi
- Responsive tasarım

## 🛠️ Kullanılan Teknolojiler

- C#
- ASP.NET Core MVC
- HTML5
- CSS3
- JavaScript
- Bootstrap

## 🎨 Proje Hakkında

GoldNAZORA, modern ve zarif bir tasarım anlayışıyla hazırlanmıştır. Altın tonları, sade renk paleti ve kullanıcı dostu arayüzüyle online takı mağazası deneyimi sunmayı amaçlamaktadır.
